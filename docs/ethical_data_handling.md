# Ethical Data Handling

This public portfolio deliberately separates professional context from confidential operational data.

## Never publish

- NIN or other government identifiers
- BVN
- phone numbers
- beneficiary/household names
- exact addresses
- sensitive household characteristics that could identify a person
- raw production exports
- internal forms, questionnaires, reports, or restricted documents
- authentication credentials, API keys, access tokens, or private URLs

## Portfolio approach

Where a real workflow would use sensitive information, this repository uses:

- synthetic IDs;
- synthetic community labels;
- fictional records;
- generic categories; and
- intentionally introduced test errors.

The purpose is to demonstrate **how data is handled and quality-checked**, not to expose the underlying people or operational database.

## Fabrication boundary

The portfolio may demonstrate a workflow using invented records. It must not present invented records as actual NASSCO/SOCU beneficiaries, official statistics, or real programme findings.
