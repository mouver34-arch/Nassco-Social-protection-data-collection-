# Methodology

## Scope

This document describes the public portfolio demonstration, not an internal NASSCO/SOCU operating procedure.

## Workflow

1. Enumerate households using a structured digital form.
2. Capture required fields using safe, predefined field rules.
3. Review records for completeness.
4. Validate field formats and allowed categories.
5. Detect duplicates and discrepancies.
6. Resolve or flag issues using transparent rules.
7. Produce a cleaned analytical copy while retaining the original demonstration input.
8. Generate a data-quality report.
9. Summarize results for operational or analytical review.

## Field practice

In real field operations, validation also involves communication with respondents, community engagement and clarification of discrepancies. This repository demonstrates the analytical side of that process using fictional records.
